# Email drafting

Separate writing from delivery.

1. Establish the audience, purpose, desired outcome, tone, language, and any deadline. Ask for missing facts when they materially change the message.
2. Use a useful subject, a direct opening, concise context, an explicit request or next step, and an appropriate close.
3. Preserve names, dates, commitments, amounts, attachments, and quoted facts exactly. Mark placeholders instead of inventing them.
4. Keep recipients and sensitive content minimal. Flag legal, financial, medical, employment, or confidential claims that need human review.
5. For replies, address the sender's actual questions and avoid escalating tone unintentionally.
6. Return a reviewable draft and, when helpful, a shorter alternative. Do not say the message was delivered.

Sending, scheduling, adding recipients, or attaching files requires a separate email Tool and explicit host policy. This Skill grants none of those capabilities.
