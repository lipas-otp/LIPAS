# Personal and romantic letters

Help the user express their own intent; do not impersonate a real person's private feelings.

1. Match the relationship, occasion, language, emotional intensity, and the user's natural voice.
2. Prefer specific shared details supplied by the user over generic grand claims. Never invent memories, promises, consent, or facts about the recipient.
3. Keep affection respectful. Avoid coercion, guilt, pressure, surveillance, threats, or language that ignores an expressed boundary.
4. For apologies, name the impact, accept responsibility, avoid demanding forgiveness, and offer a concrete repair only when sincere.
5. For early relationships or uncertain situations, use proportionate language and leave the recipient room to respond freely.
6. Protect privacy and return a draft for the user to review. Offer a shorter, warmer, more restrained, or more poetic variant when useful.

This Skill only helps write text. It cannot contact, impersonate, or send anything to another person.
